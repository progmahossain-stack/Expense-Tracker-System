# 💰 Expense Tracker System

Welcome to the **Expense Tracker System** — a simple and practical desktop application built to help you record, organize, and monitor your daily expenses with ease! 📊

## 🌟 Features

- **🔐 Secure Login:** User registration and login to keep your financial data private and secure.
- **➕ Expense Management:** Add, edit, and delete expense records anytime.
- **🏷️ Category Management:** Organize expenses into categories like Food, Transport, Shopping, and Bills.
- **🔍 Search Expenses:** Quickly find past expenses by date or category.
- **📈 Reports & Dashboard:** View daily and monthly reports with a clear spending summary.

## 🛠️ Technologies Used

- **Language:** C#
- **Framework:** .NET (Windows Forms)
- **Database:** Microsoft SQL Server
- **IDE:** Microsoft Visual Studio
- **Version Control:** Git & GitHub

## 🚀 About

Managing personal expenses is a part of everyday life, but many people don't keep proper records of their spending. The **Expense Tracker System** solves this by giving students, employees, and anyone managing personal finances a simple, user-friendly way to track spending and generate reports — following the **Agile Software Development Model** for flexible, organized development. 🎯
